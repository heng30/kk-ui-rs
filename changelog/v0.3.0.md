# v0.3.0

菜单行新增三种取值控件，动画底座换成定点弹簧；位掩码改为弹窗逐位编辑。交互仍然只有
上/下/确定三个键。

## 新增

- 定点弹簧 `ui/spring.rs`：Q8 定点的半隐式欧拉积分，子步长 8 ms，参数按 SwiftUI 的
  Response / Damping 预乘成整数（`SPRING_CHIP`、`SPRING_BOUNCY`）。不需要浮点，
  一个动画值只占三个整数。
- `ChipBinding` 分段单选行（`src/widgets/chip.rs`）：菜单行右列是等宽的 N 段文字，
  选中段套异或框，按确定在段间循环换档，末档回到首档；换档时选中框滑动过去。
- `BitsBinding` 位掩码（`src/widgets/toggle.rs`、`src/widgets/dialog/bits_editor.rs`）：
  行上给一排方片预览，置位画实心；按确定打开一列带名字的方片，上/下只移游标
  （跳过某位不会翻转它），确定翻转当前位，翻转时方片从中心弹开。屏矮时弹窗只显示
  几行并滚动，游标自动滚进可见范围。
- `ChoiceBinding` 枚举选择（`src/widgets/dialog/choice_editor.rs`）：行上显示当前标签，
  确定打开弹窗，上/下换标签（往下选下一个，与整数编辑器方向相反），新旧标签纵向滚动。
- 跑马灯（`src/widgets/marquee.rs`）：焦点行放不下时，先停 900 ms，再按每秒 24 像素
  匀速滑到尾部，停一下后匀速回位。位置按「阶段起点 + 速度」现算，不做缓动，掉帧也不会
  越走越偏。
- `Runtime::open_choice_editor()` 与 `Runtime::open_bits_editor()`：可在自绘页回调里
  登记，回调退出后统一打开；`Runtime::get_bits_editor_draft()` 读取位掩码草稿。
- `MAX_BITS`（8）：一行方片的位数上限。
- 演示新增「取值控件」页（设置页第 1 行入口），一屏展示分段单选、位掩码、枚举选择与
  一条放不下的长标签；自动演示为位弹窗补上「走位 / 翻转」交替按键。
- 加载弹窗（`src/widgets/dialog/loading.rs`）：`Runtime::show_loading()` 开一个宽度随文案
  自适应的小方框（高 52，左右各留 8 px），上面一圈半径 10 的 8 个点顺时针每 120 ms 转一格、
  当前点画大一号，下面一行文案。打开期间吞掉所有按键，只能由 `Runtime::hide_loading()`
  关闭；与其它弹窗一样可在自绘页回调里登记、回调退出后打开。已有覆盖层时返回 `Busy`，
  没有加载弹窗时关闭返回 `NotAllowed`。
- 缓动曲线从一条扩到五条（`src/ui/anim.rs`）：标准、减速、加速、过冲、缓入缓出，都是
  Q12 查表，`Overshoot` 允许进度超过 1。页面转场用减速、fade 用缓入缓出、弹窗开用减速、
  关用加速，滚动数字用过冲。
- 滚动数字（`src/widgets/roll.rs`）：文本逐位垂直滚动，多位同时变化时从右往左错峰。
  菜单右列取值与整数编辑器的取值都改成逐位滚，字符数变了就直接跳过去。
- 小图标助手（`src/widgets/icons.rs`）：`draw_chevron`、`draw_battery`、`draw_wifi`、
  `draw_spinner`，全整数坐标，受裁剪窗口约束。加载弹窗的转圈改用它。
- 公共滚动条（`src/widgets/scrollbar.rs`）：`Scrollbar` 收掉菜单页与信息页原先各写一份的
  几何计算，可配粗细、最短滑块与是否画轨道线。
- 按页差分提交（`src/gfx.rs`、`src/ui/runtime.rs`、`src/ui.rs`）：`Frame::pages()` /
  `Frame::page_hash()` 按 SSD1306 页格式算 FNV-1a，`KkUi::take_dirty_pages()` 返回自上次
  调用以来变化的页位掩码。首次调用返回全 1；画布高过 32 页（256 px）时一律返回全 1，
  交给应用整帧提交。
- `TransitionKind::Fade` 与 `KkUi::set_transition_kind()`：淡入淡出用互补的有序抖动掩码
  交错，不需要第二块帧缓冲；默认仍是滑动。
- `InputAction::Back` 与确定键长按：确定键改为松开时结算，按住超过 400 ms 松开就是返回
  （`KEY_OK_LONG_MS`），短按仍是确认。弹窗里等同取消（确认框跳到取消并执行，其余直接
  关闭不提交），菜单与信息页退回上一页，首页无动作。转场期间按住的确定键不结算。
- 电源阶段（`src/ui/power.rs`）：`KkUi::idle_ms()` 报距最近一次按键或编码器动作的毫秒数，
  `power_phase()` 按 `set_power_timeouts()` 设的两个阈值返回 `Awake` / `Dim` / `Sleep`。
  库不碰显示驱动，对比度与背光由应用按阶段自己调；阈值任一项为 0 表示该阶段不启用。
- 测试：`tests/widgets.rs`、`tests/menu_scroll.rs`，以及弹簧、跑马灯、方片、滚动数字、
  滚动条、小图标、曲线、电源阶段的单元用例。
