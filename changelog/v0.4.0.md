# v0.4.0

屏幕上能打字了：菜单行可以接一个单行输入框，按确定弹出带软键盘的编辑器。动画曲线扩到
五条，菜单右列与弹窗里的取值逐位滚动；新增按页差分提交、淡入淡出转场、确定键长按返回
与电源阶段。

## 新增

- 单行输入框（`src/model.rs`）：`LineInput` 是 64 字节的定长共享文本（`LINE_INPUT_LEN`，
  按 UTF-8 计），`literal` / `set` / `with` / `push` / `pop` 都在字符边界上动，写满时整字
  丢弃、已存内容不受影响。`LineInputBinding` 把标题、值与 `changed_event` 绑在一起，应用在
  `App::line_inputs` 里登记后可用 `Runtime::open_line_input()` 打开，
  `Runtime::line_input_open()` 查它是否正开着。菜单项用 `MenuAction::LineInput`：右列显示
  当前文字，确定打开编辑器。
- 软键盘弹窗（`src/widgets/dialog/line_input.rs`）：顶上一条预览行显示正在编辑的文字与
  末尾光标，下面四行键位——三行字符加一行功能键（`123`/`abc` 切层、空格、`esc`、`ok`）。
  字母层与数字符号层各一套字符表，`C` 是锁定式大写。面板只有上、下、确定三个键：上下键
  在行内横向走，确定踩当前键，光标停在原地可以连按同一个键输出重复字符；每行两端各有一个
  换行按钮（用 `draw_caret` 画的上下箭头），退格只在字符区最后一行。弹窗占满整屏、不画
  焦点框，屏矮时字形被裁剪。提交时文字与绑定不同才写回并入队 `changed_event`，否则直接关。
  键盘上长按确定等同按一下键，不会被当成返回关掉弹窗；返回只剩 `esc` 与面板的取消键。
- 缓动曲线从一条扩到五条（`src/ui/anim.rs`）：标准、减速、加速、过冲、缓入缓出，都是
  Q12 查表，`Overshoot` 允许进度超过 1。页面转场用减速、fade 用缓入缓出、弹窗开用减速、
  关用加速、滚动数字用过冲。
- 滚动数字（`src/widgets/roll.rs`）：文本逐位垂直滚动，多位同时变化时从右往左错峰。菜单
  右列取值与整数编辑器的取值都改成逐位滚，字符数变了就直接跳过去；整数编辑器的逐位滚要
  300 ms 而数值补间只有 100 ms，放慢期间持续重画，数字不会停在半路等下一次按键。
- 小图标助手（`src/widgets/icons.rs`）：`draw_chevron`、`draw_caret`、`draw_battery`、
  `draw_wifi`、`draw_spinner`，全整数坐标，受裁剪窗口约束。`draw_caret` 是上下方向的尖角，
  以 `cy` 为中心上下对称；加载弹窗的转圈与软键盘的换行按钮用它画。
- 公共滚动条（`src/widgets/scrollbar.rs`）：`Scrollbar` 收掉菜单页与信息页原先各写一份的
  几何计算，可配粗细、最短滑块与是否画轨道线。
- icons8 动图（`src/widgets/anim_icons.rs`、`assets/icons/animators/`）：483 个 24 fps 动图，
  每个动图的每一档尺寸各是一个静态（`ACTIVITY_32` / `ACTIVITY_48` / `ACTIVITY_64`），边长由
  `IconSize` 枚举（`Px32` / `Px48` / `Px64`，`px()`、`frame_len()`、`ALL`）给出，只引用哪一档
  就只多出那一档的字节数（32 档约 3.5 KiB、64 档约 14 KiB）。`draw_anim_icon` 按帧号画、
  `draw_anim_icon_at` 按经过毫秒取帧，尺寸取自 `AnimIcon::size`、不用再传。静态由模块文件
  末尾一次 `anim_icons!` 声明，整个模块由 `anim-icons` 特性控制、默认不编译；`anim_icons!`
  也能给应用自己的 `assets/icons/animators/` 按 `名字 = "文件名" @ Px32` 声明动图（路径由
  `CARGO_MANIFEST_DIR` 拼出）。首页入口的图标同样可以是动图（`HomeIcon::Anim`），没有输入时
  按 24 fps 自己换帧重画，只有静态图标时不动。图形来自 icons8.com（免费使用需署名）。
- 静态图标（`src/widgets/icons.rs`、`assets/icons/statics/`）：32×32 XBM 的 `ICON_SETTINGS`、
  `ICON_MONITOR`、`ICON_WAVE`、`ICON_ABOUT` 由 `static_icons!` 宏按 `名字 = "文件名"` 声明并
  导出（文件是 `settings.bin` / `monitor.bin` / `wave.bin` / `about.bin`，路径同样用
  `CARGO_MANIFEST_DIR` 拼），用 `Frame::draw_xbm` 画；示例首页的四张图标改成引用库里的这几张，
  `examples/sim/assets/` 只剩字库与 `math.bin`。
- 按页差分提交（`src/gfx.rs`、`src/ui/runtime.rs`、`src/ui.rs`）：`Frame::pages()` /
  `Frame::page_hash()` 按 SSD1306 页格式算 FNV-1a，`KkUi::take_dirty_pages()` 返回自上次
  调用以来变化的页位掩码。首次调用返回全 1；画布高过 32 页（256 px）时一律返回全 1，
  交给应用整帧提交。
- `TransitionKind::Fade` 与 `KkUi::set_transition_kind()`：淡入淡出用互补的有序抖动掩码
  交错，旧页画在掩码内、新页画在掩码外，不需要第二块帧缓冲；默认仍是滑动。
- `InputAction::Back` 与确定键长按：确定键改为松开时结算，按住超过 400 ms 松开就是返回
  （`KEY_OK_LONG_MS`），短按仍是确认。弹窗里等同取消（确认框跳到取消并执行，其余直接
  关闭不提交），菜单与信息页退回上一页，首页无动作。转场期间按住的确定键不结算。
- 电源阶段（`src/ui/power.rs`）：`KkUi::idle_ms()` 报距最近一次按键或编码器动作的毫秒数，
  `power_phase()` 按 `set_power_timeouts()` 设的两个阈值返回 `Awake` / `Dim` / `Sleep`。
  库不碰显示驱动，对比度与背光由应用按阶段自己调；阈值任一项为 0 表示该阶段不启用。
- 演示：新增「图标」页（电池、无线、箭头、转圈）与「控件」页（进度条、开关、滚动条、焦点框，
  挂在组件演示页末行），首页末尾新增「动图」入口（入口图标本身就是动图），页里 4×2 摆 8 个
  32×32 动图；监控页补上空闲、电源阶段与脏页三行以及「淡入淡出」开关，设置页新增接输入框的
  「设备名称」条目。
- 测试：单行输入框的四组用例，以及弹簧、跑马灯、方片、滚动数字、滚动条、小图标、曲线、
  电源阶段的单元用例。

## 变更

- 首页入口的图标类型：`HomeItem.icon` 从 `&'static [u8]` 变成 `HomeIcon`，静态 XBM 要包一层
  `HomeIcon::Static(...)`。

## 移除

- 滑屏转场分界处的竖直白条：两页各自按边界裁剪，本来就不留缝。
